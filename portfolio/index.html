Multimodal AI Deep Dive

Visual Question Answering using LLaMA & ConceptNet

Duration: Sep 2025 – Apr 2026 | Domain: Computer Vision + NLP + Knowledge Graphs

Architecture Overview

Traditional VQA systems frequently hallucinate or fail when questions demand real-world commonsense knowledge beyond raw visual object classification. In this project, I bridged this gap by designing an end-to-end multimodal pipeline:

1. Image Input & Feature Extraction → 2. ConceptNet Entity Graph Expansion → 3. LLaMA Context Integration → 4. Grounded Natural Language Answer

Key Technical Innovations

  • Commonsense Reasoning: Leveraged ConceptNet triples (e.g., IsA, UsedFor, CapableOf) to provide ontological groundings for recognized objects.
  • LLaMA Prompt Tuning: Structured prompt sequences conditioning the foundation model on both bounding boxes/semantic features and external knowledge triples.
  • Performance Optimization: Reduced latency for real-time querying by implementing quantized weights and efficient key-value caching.

Tools & Libraries Used

Python PyTorch LLaMA ConceptNet 5 API HuggingFace Transformers OpenCV

ChatterBox – Real-Time Chat Application

Duration: Aug 2024 – Dec 2024 | Domain: Low-Latency Socket Programming & GUI Design

System Design

ChatterBox was engineered from first principles to explore low-level network protocols and concurrent socket programming in Python, providing seamless desktop communication without relying on third-party cloud messaging SDKs.

Key Engineering Highlights

  • Multi-Threaded Server Core: Built a non-blocking TCP socket server capable of maintaining simultaneous persistent connections with thread pools.
  • Protocol Design: Formatted custom JSON/binary payload packets for message routing, user registration, heartbeat ping/pong, and error events.
  • Dynamic Presence & Conflict Handling: Handled client disconnects gracefully and prevented username collisions using atomic locks.
  • Interactive Kivy Interface: Developed an asynchronous GUI using Kivy, decoupling the networking I/O loop from UI rendering to prevent frame stutter.

Tools & Libraries

Python 3 Sockets (TCP/IP) Threading Kivy Framework Network Protocols

Machine Learning Pipeline

Heart Stroke Prediction using Hybrid ML Models

Duration: Jan 2024 – Apr 2024 | Repository: github.com/riteeshkumargudipudi/heart-stroke-prediction

Objective & Clinical Challenge

Early risk identification of cardiovascular accidents (strokes) is challenging due to extreme class imbalance in clinical datasets and intricate non-linear biomarker correlations.

Methodology

  • Data Preprocessing: Handled missing clinical records, applied SMOTE (Synthetic Minority Over-sampling Technique) to balance stroke cohorts, and normalized continuous features (blood glucose, BMI, age).
  • Hybrid Ensembling: Combined Decision Trees, Random Forests, XGBoost, and Logistic Regression via Soft Voting, capitalizing on individual model strengths while minimizing variance.
  • Results: Elevated detection recall to safeguard against false negatives while sustaining high overall classification precision.
